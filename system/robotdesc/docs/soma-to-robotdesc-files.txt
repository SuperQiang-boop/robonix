# Soma → Robotdesc 迁移文件清单

本清单记录本轮 `soma` → `robotdesc` 的路径迁移和内容更新。路径均相对
`/data/robonix`；工作树中 Atlas→Src、Pilot→Planner、Liaison→Gateway、
Scene→World 等已有修改保持不动，清单不把它们回滚或拆分。

## 排除项

- `CHANGELOG.md` 中的历史发布记录不改。
- `target/`、`rbnx-build/`、`rbnx-boot/`、缓存、备份文件和历史生成物不作为源码迁移输入。
- 本轮不手工编辑 codegen 生成的 protobuf/gRPC 文件；通过源 IDL、contract 和 `cargo build`/`rbnx codegen` 重生成。
